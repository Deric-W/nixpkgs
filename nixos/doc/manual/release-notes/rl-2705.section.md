## Backward Incompatibilities {#sec-release-27.05-incompatibilities}

<!-- To avoid merge conflicts, consider adding your item at an arbitrary place in the list instead. -->

- `services.fail2ban` now disallows modifying the generated configuration using [`environment.etc`](#opt-environment.etc), use the new module options instead.

- [](#opt-services.mealie.settings) has a proper type now:
  - Booleans are coerced to `"true"` and `"false"` instead of `"1"` and `""`.
  - Values other than booleans, ints, strings, paths or packages will be rejected.
  - `null` values now unset the value instead of producing an empty string.

## Other Notable Changes {#sec-release-27.05-notable-changes}

<!-- To avoid merge conflicts, consider adding your item at an arbitrary place in the list instead. -->

- `services.fail2ban` now has options for specifying custom [`actions`](#opt-services.fail2ban.actions) and [`filters`](#opt-services.fail2ban.filters) or overriding existing ones, replacing manually doing so via [`environment.etc`](#opt-environment.etc).

- `services.fail2ban` now supports checking the generated configuration during building, which is enabled by default.
